# 🚀 AI/ML Fundamentals: My Journey Through the Piscine

[🇷🇺 Описание на русском языке](#russian-description)

This repository documents my intensive learning path in Artificial Intelligence and Machine Learning at **Tomorrow School (Astana Hub / 01edu)**. The projects are structured chronologically, following the "AI Piscine" methodology, starting from raw data manipulation to advanced predictive modeling.

## 📂 Project Chronology

### 1. Unsupervised Learning: Dimensionality Reduction (PCA)
*   **Topic:** WINE-PCA-ANALYSIS
*   **Goal:** Applied Principal Component Analysis (PCA) to reduce the dimensionality of high-dimensional datasets while preserving maximum variance.
*   **Skills:** Eigenvalues, Covariance matrix, Feature projection, Scree plots.

### 2. Statistical Analysis: A/B Testing & Hypotheses
*   **Topic:** CHECKOUT-EXPERIMENT-ANALYSIS
*   **Goal:** Evaluated a business experiment using statistical inference. Calculated p-values and confidence intervals to determine if changes in the checkout flow significantly impacted conversion rates.
*   **Skills:** Z-tests, T-tests, Null Hypothesis significance testing (NHST), Distributions.

### 3. Data Engineering: Preprocessing & Cleaning
*   **Topic:** TITANIC-DATA
*   **Goal:** Transformed a "messy" real-world dataset into a machine-learning-ready format. Handled missing values, outliers, and data type inconsistencies.
*   **Skills:** Pandas pipelines, Data imputation, Outlier detection.

### 4. Exploratory Data Analysis (EDA)
*   **Topic:** CALI-SCOPE (California Housing)
*   **Goal:** Conducted a deep dive into the California Housing dataset. Visualized correlations, analyzed geographic distributions, and identified key drivers of property prices.
*   **Skills:** Matplotlib, Seaborn, Feature correlation, Multivariate analysis.

### 5. Supervised Learning: Titanic Survival Prediction
*   **Topic:** TITANIC-SURVIVAL
*   **Goal:** Built a classification pipeline to predict passenger survival. Demonstrated the power of **Feature Engineering** (Age bands, Family size, IsAlone) by improving baseline accuracy by **10%+.**
*   **Skills:** Logistic Regression, Random Forest, Scikit-learn, Model evaluation (Precision/Recall).

## 🇷🇺 Мой путь в AI/ML: Структура «Бассейнов»

В этом репозитории собраны результаты моего обучения на ии-бассейнах в **Tomorrow School (Astana Hub / 01edu)**. Проекты расположены в хронологическом порядке, отражая переход от базовой обработки данных к созданию полноценных моделей машинного обучения.

## 📂 Хронология проектов

### 1. Обучение без учителя: Понижение размерности (PCA)
*   **Проект:** Анализ вин через PCA.
*   **Суть:** Использование метода главных компонент для сжатия признаков с сохранением максимума полезной информации.
*   **Навыки:** Собственные числа, матрица ковариации, визуализация дисперсии.

### 2. Статистика: A/B Тестирование и гипотезы
*   **Проект:** Анализ процесса оформления заказа (Checkout).
*   **Суть:** Проверка статистической значимости изменений в интерфейсе. Работа с p-value и доверительными интервалами для принятия бизнес-решений.
*   **Навыки:** Гипотезы, Z-тесты, распределения данных.

### 3. Инженерия данных: Препроцессинг и очистка
*   **Проект:** TITANIC-DATA.
*   **Суть:** Превращение «грязных» данных в готовый для ML формат. Обработка пропусков, выбросов и аномалий.
*   **Навыки:** Пайплайны Pandas, очистка данных, работа с форматами.

### 4. Исследовательский анализ данных (EDA)
*   **Проект:** CALI-SCOPE (Цены на жилье в Калифорнии).
*   **Суть:** Глубокий визуальный анализ данных. Поиск корреляций и географических закономерностей, влияющих на стоимость.
*   **Навыки:** Построение графиков (Matplotlib/Seaborn), корреляционный анализ.

### 5. Обучение с учителем: Предсказание выживаемости на Титанике
*   **Проект:** TITANIC-SURVIVAL.
*   **Суть:** Создание модели классификации. Главный фокус на **Feature Engineering** (создание новых признаков), что позволило поднять точность модели более чем на **10%** по сравнению с базовой версией.
*   **Навыки:** Логистическая регрессия, Random Forest, оценка метрик (Precision, Recall).
