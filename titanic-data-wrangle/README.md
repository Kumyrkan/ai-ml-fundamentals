Titanic Wrangling Project

📌 Описание

Этот проект реализует полный пайплайн очистки и анализа данных пассажиров «Титаника» с помощью pandas и numpy.
Скрипт titanic_clean.py загружает исходный датасет, чистит его, добавляет новые признаки (размер семьи, возрастные группы, группы по цене билета), считает выживаемость по разным категориям и объединяет данные с таблицей портов посадки.
⚙️ Установка

    Установите Python 3.10+ (подойдёт и 3.9, но в задании рекомендуют 3.10).

    Создайте виртуальное окружение:
    bash

    python3 -m venv ex00
    source ex00/bin/activate

    Установите зависимости:
    bash

    pip install -r requirements.txt

🚀 Запуск

    Запустить тесты (проверка очистки данных):
    bash

    python -m pytest test_titanic_clean.py -v

    Ожидаемый результат: три теста PASSED.

    Запустить основной скрипт:
    bash

    python titanic_clean.py

    Скрипт выведет:

        форму таблицы до и после очистки,

        общую выживаемость,

        выживаемость по полу, классу, возрастным группам, признаку «один/с семьёй»,

        выживаемость по портам и странам.

📊 Результаты

    Общая выживаемость: 38%.

    Женщины: 74%, мужчины: 19%.

    Первый класс: 63%, третий класс: 24%.

    Дети выживали чаще всех (58%).

    Одинокие пассажиры: 30%, с семьёй: 50%.

    По портам: Southampton — 34%, Cherbourg — 55%, Queenstown — 39%.

📝 Вывод

На «Титанике» лучше всего было быть женщиной или ребёнком из первого класса и путешествовать не одному. Разница по портам посадки может объясняться составом классов, поэтому прямых выводов делать нельзя.
